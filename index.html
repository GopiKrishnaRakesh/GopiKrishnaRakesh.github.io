Python Reels Poster

Python Reels Poster is the private publishing tool behind this channel. It uploads LearnPython2027's own pre-made lesson videos to the channel's own YouTube account on a daily schedule, with the title, description and playlist for each lesson.

  • It is used only by the channel owner, for the channel owner's own YouTube channel.
  • It runs on the owner's own computer (a self-hosted instance of the open-source scheduler Postiz).
  • It uses the YouTube Data API to upload videos and add them to playlists, and the YouTube Analytics API to read the channel's own view counts.
  • It does not access, collect or store data about any other YouTube user.
